.. attribute:: dialog_size
   :noindex:

   The size of the dialog in which the view is rendered, when it is opened as a dialog (e.g. an
   action with ``target="new"``, a many2one "search more"/"create and edit", or an x2many form
   dialog). It has no effect when the view is not rendered inside a dialog.

   :requirement: Optional
   :type: str, one of `sm`, `md`, `lg`, `xl`, `fs`, `fullscreen`
   :default: `''`
