==============
Insert a chart
==============

To insert a chart from an Odoo database into an Odoo spreadsheet:

#. With the relevant graph view open in your database, click :guilabel:`Spreadsheet`.
#. In the window that opens, edit the :guilabel:`Graph name` if needed.

#. Click :guilabel:`Blank spreadsheet` to create a new spreadsheet, or select in which existing
   spreadsheet the chart should be inserted.

   .. note::
      When inserting a chart into a new spreadsheet, the spreadsheet is saved in the **Odoo
      Documents** app in the :icon:`storage` :guilabel:`My Drive` personal folder.

#. Click :guilabel:`Confirm`.

Charts are inserted on the first sheet of the spreadsheet. A panel on the right side of the screen
shows the chart properties, where various aspects of the chart's :ref:`configuration and design can
be customized <spreadsheet/charts/customize>`.

.. seealso::
   :ref:`Manage charts <spreadsheet/charts/manage>`

.. tip::
   Clicking on a data point in a chart opens the relevant list view in the database. In the example,
   clicking on :guilabel:`Marc Demo` opens the list view of all sales by this salesperson that
   match the domain of the chart.
